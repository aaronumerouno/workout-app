# Workout Plan

**Profile:** Male, 110kg, goal = fat loss + muscle toning, 90 minutes max per gym session, starting load 20kg on main lifts.

## Weekly Split

| Day | Session |
|-----|---------|
| Mon | Full Body Strength A |
| Tue | Cardio & Core |
| Wed | Full Body Strength B |
| Thu | Rest / Active Recovery |
| Fri | Full Body Strength C |
| Sat | Cardio & Core |
| Sun | Rest / Active Recovery |

4 training days + 2 conditioning days keeps each session short enough to fit 90 minutes while still hitting every major muscle group twice a week and getting enough cardio volume to support fat loss.

## Session Structure (Strength Days, ~90 min)

- Warm-up — 10 min (easy bike/treadmill + dynamic stretches)
- Main lifts — ~60 min (5 exercises, 3 sets each, 60–90s rest)
- Cool-down / stretch — 10–15 min

### Full Body Strength A (Mon)
1. Goblet Squat — 3x12 — start 20kg
2. Dumbbell Bench Press — 3x10 — start 20kg
3. Bent-Over Row — 3x12 — start 20kg
4. Dumbbell Shoulder Press — 3x10 — start 20kg
5. Plank — 3x45s hold

### Full Body Strength B (Wed)
1. Romanian Deadlift — 3x10 — start 20kg
2. Lat Pulldown — 3x10 — start 20kg
3. Walking Lunges — 3x12/leg — start 20kg
4. Incline Dumbbell Press — 3x10 — start 20kg
5. Russian Twists — 3x20

### Full Body Strength C (Fri)
1. Deadlift — 3x10 — start 20kg
2. Push-Ups / DB Floor Press — 3x12 — bodyweight or 20kg
3. Seated Cable Row — 3x12 — start 20kg
4. Lateral Raises — 3x12 — start 8kg
5. Mountain Climbers — 3x30s

## Cardio & Core (Tue/Sat, ~60 min)

1. Warm-up walk — 5 min
2. Steady-state cardio (treadmill incline / elliptical / bike) — 25 min, Zone 2
3. HIIT intervals (bike or row: 30s hard / 90s easy x5) — 10 min
4. Core circuit — Plank 3x45s, Bicycle Crunch 3x20, Leg Raises 3x15, Side Plank 2x30s/side
5. Stretch / cool-down — 10 min

## Rest Days (Sun/Thu)

Optional light walk, stretching, or foam rolling. No lifting required. If you're feeling up for it, the app offers a "Train anyway" bonus full-body session (deadlift, floor press, goblet squat, one-arm row, plank) you can opt into without changing the recurring schedule.

## Progression Rule

Once you complete all sets at the top of the rep range with good form for **two sessions in a row**, add **2.5kg** to that lift. Expect squat/deadlift/row to progress faster than press/shoulder work — that's normal.

## Weight Tracking

Log bodyweight weekly (same day, same conditions — e.g. Monday morning). Target pace: **0.5–1kg loss per week**. This requires a modest calorie deficit alongside training; the app tracks bodyweight trend but programming your diet is on you.
